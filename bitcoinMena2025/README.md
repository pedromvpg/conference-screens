# Bitcoin Amsterdam 2025 Conference Screens

## Setup

Copy the config template and add your Airtable credentials:

```bash
cp config.example.js config.js
```

Edit `config.js` with your API keys. Don't commit `config.js` to git.

## Screens

- `led_a_sponsors.html` - Main LED sponsor display
- `treasury_stage_sponsors.html` - Treasury stage sponsors
- `genesis_stage_sponsors.html` - Genesis stage sponsors  
- `led_c_title_bitcoin_asia.html` - Event schedule
- `price.html` - Bitcoin price
- `hashrate.html` - Network hashrate
