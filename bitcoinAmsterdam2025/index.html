Option 1: URL Parameters (Recommended for GitHub Pages)

For Sponsors pages only:
?sponsorsAccessToken=TOKEN&sponsorsBaseId=BASE&sponsorsTableName=TABLE
For Agenda/LED C pages only:
?agendaAccessToken=TOKEN&agendaBaseId=BASE&agendaTableName=TABLE
For ALL pages (recommended):
?sponsorsAccessToken=TOKEN1&sponsorsBaseId=BASE1&sponsorsTableName=TABLE1&agendaAccessToken=TOKEN2&agendaBaseId=BASE2&agendaTableName=TABLE2
Note: If using same credentials for both, just provide sponsors parameters - they'll be shared automatically.
